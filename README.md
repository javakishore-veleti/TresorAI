## What it is

TrésorAI is an **agentic AP-fraud + cash-flow copilot for SMBs**. A live transaction stream feeds an LLM-as-judge agent loop (Gemini 2.0 Flash + tool use + pgvector embeddings) that scores each transaction, drafts a Hold / Release / Alert decision with a **visible reasoning trace**, and updates a 30/60/90-day cash-flow forecast.

Two SPAs sit on top of one polyglot backend:

- **`portal-customer`** — what the SMB CFO uses every day: live transaction feed, agent reasoning trace, forecast, flagged-tx review.
- **`portal-admin`** — what TrésorAI ops + enterprise client admins use to install, configure, and operate the system at multiple client locations. Three-level navigation (top-nav → left-nav → content); the Initial Downloads page is the structured way every client install seeds reference data.

## Why

- **Agentic UX, not chatbot UX.** The reasoning trace is rendered live — visitors literally see the agent thinking. _(see [ADR-0004](docs/adr/0004-gemini-flash-for-agent-loop.md))_
- **Polyglot is deliberate.** Java + Spring Kafka owns the streaming spine; Python + FastAPI owns the AI tier. _(see [ADR-0001](docs/adr/0001-monorepo-with-independent-module-deploys.md), [ADR-0002](docs/adr/0002-streaming-spine-via-kafka.md))_
- **Professional install discipline.** No manual / ad-hoc downloads anywhere — every install operation runs from the admin portal or its CLI counterpart. _(see [ADR-0007](docs/adr/0007-no-adhoc-downloads-install-discipline.md))_
- **Independent module deploys.** One Cloud Run service per module; touching one module rebuilds and redeploys only that module. _(see [ADR-0005](docs/adr/0005-cloud-run-over-kubernetes.md))_

## Quickstart

> Quickstart only sets up the dev environment — the application services themselves are not scaffolded yet. See the roadmap below.

```bash
# 1. Set up the conda env at $HOME/runtime_data/python_venvs/TresorAI
npm run setup:conda:create

# 2. Activate (must be sourced)
source ./scripts/conda-activate.sh

# 3. Bring up local infra (postgres + pgvector, redis, kafka)
npm run infra:up
npm run infra:status

# 4. (Once intelligence-service is scaffolded) install Python deps
npm run setup:python:deps

# Or run the full sequence:
npm run setup:initial:all

# Tear down
npm run infra:down
source ./scripts/conda-deactivate.sh
```
